# Obrázky a video

Sem patří fotky, loga a video z WordPressu (**Média → Knihovna**, u souboru „Stáhnout soubor“).
Názvy souborů nechte přesně tak, jak je WordPress stáhne. Web na ně odkazuje přesně těmito jmény.

Nahrání přes GitHub: v této složce **Add file → Upload files**, přetáhnout soubory, **Commit changes**.
Limit je 25 MB na soubor (týká se hlavně videa `Brno.mp4`).
